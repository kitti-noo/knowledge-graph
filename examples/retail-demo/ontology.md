# Ontology: ระบบค้าปลีก

ไฟล์นี้คือกติกาของกราฟ โค้ดจะอ่านเฉพาะตารางสองตารางด้านล่าง (คอลัมน์แรกของแต่ละแถว) ส่วนข้อความอื่นมีไว้ให้คนอ่าน

## Entity types

| Type       | ความหมาย                  | ตัวอย่าง                    |
|------------|--------------------------|----------------------------|
| System     | ระบบงาน                   | POS, RMS, CRM              |
| DataObject | ข้อมูลที่ส่งระหว่างระบบ        | Price, Coupon              |
| Interface  | ช่องทางส่งข้อมูล              | Price batch 02:00          |
| Team       | ทีมเจ้าของ / ผู้ดูแล            | ทีม CRM                    |
| Channel    | ช่องทางขาย                 | หน้าร้าน, เว็บไซต์              |

## Relations

| Relation   | จาก → ไป                | ความหมาย                                     |
|------------|------------------------|---------------------------------------------|
| SENDS_TO   | System → System        | ส่งข้อมูลให้ (ถ้าต้นทางล่ม ปลายทางไม่ได้รับข้อมูล)    |
| DEPENDS_ON | System → System        | ทำงานไม่ได้ถ้าอีกระบบล่ม                        |
| PRODUCES   | System → DataObject    | เป็นต้นทาง (master) ของข้อมูล                  |
| CONSUMES   | System → DataObject    | ใช้ข้อมูลนี้                                    |
| VIA        | DataObject → Interface | ข้อมูลนี้ส่งผ่านช่องทางนี้                         |
| OWNED_BY   | System → Team          | ทีมที่ดูแล                                     |
| USED_IN    | System → Channel       | ใช้ในช่องทางขายนี้                               |

## กติกาเพิ่มเติม

- เวลา ความถี่ เวอร์ชัน ให้ใส่ในคอลัมน์ `note` ของ triples.csv ไม่ต้องสร้างเป็น node
- `A SENDS_TO B` หมายความว่า A เป็นผู้ส่ง
