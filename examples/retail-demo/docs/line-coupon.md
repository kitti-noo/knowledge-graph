# โน้ตประชุม: แจกคูปองผ่าน LINE (ข้อมูลสมมติ)

ระบบคูปองเป็นผู้สร้างคูปองที่แจกผ่าน LINE OA ระบบคูปองต้องพึ่งระบบสมาชิกเพื่อเช็กว่าผู้ใช้ LINE เป็นสมาชิกหรือไม่

Chatbot ส่งข้อมูลการกดรับคูปองให้ระบบคูปอง Chatbot ใช้ใน LINE OA และดูแลโดยทีม Digital

ถ้าระบบคูปองล่ม Chatbot จะแจกคูปองไม่ได้ เพราะ Chatbot ต้องพึ่งระบบคูปอง
