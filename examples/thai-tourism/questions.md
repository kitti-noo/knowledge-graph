# คำถามทดสอบ: ท่องเที่ยวไทย

รูปแบบ: `## Qn: คำถาม` ตามด้วยบรรทัด `คำตอบ: ...` ที่ถูกต้อง (คำสั่ง `eval` อ่านไฟล์นี้)

`uv run main.py eval` ได้ 2/4 เพราะ Q2 ต้องเดิน 3 ก้าว และ Q4 ต้องเดิน 4 ก้าว ส่วน `uv run main.py eval --hops 4` ได้ 4/4 (ดู docs บทที่ 2 เรื่อง `--hops`)

## Q1: ประเพณีที่ตรงกับยี่เป็งมีต้นกำเนิดที่จังหวัดใด
คำตอบ: จังหวัดสุโขทัย

## Q2: ในภาคอีสานมีมรดกโลกอะไร และมีประเพณีอะไรบ้าง
คำตอบ: มรดกโลกคือแหล่งโบราณคดีบ้านเชียง ประเพณีคือผีตาโขนและบุญบั้งไฟ

## Q3: งานฟูลมูนปาร์ตี้จัดที่เกาะไหน อยู่จังหวัดอะไร
คำตอบ: เกาะพะงัน จังหวัดสุราษฎร์ธานี

## Q4: ภาพยนตร์ The Beach ถ่ายทำในจังหวัดใด
คำตอบ: จังหวัดกระบี่
